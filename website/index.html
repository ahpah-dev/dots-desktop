Built for authentic autonomous workflows

Dots gives every agent its own persistent workspace, long-term memory scratchpad, and sandboxed system tools.

Persistent Agent Workspaces

Each Dot owns an isolated directory on disk, a dedicated scratchpad.md memory journal, and scoped permissions that persist across reboots.

Zero API Key Auto-Auth

Automatically connects to your local authenticated OpenAI Codex session via official JSON-RPC. Never copy or expose API tokens manually.

Elevated PowerShell Sandboxing

Windows container policy configured with elevated sandbox execution. Your coding agents can run tests, inspect Git repositories, and build projects without policy blocks.

Background Schedules & Tray

Runs scheduled autonomous cadences (cron / interval) when minimized or closed to the Windows system tray, protected with power suspension blocker.

Live Web Research & Chromium

DuckDuckGo search and sandboxed headless Chromium page extraction allow agents to browse the web, verify pricing, read documentation, and compile intelligence.

OS-Level Secure Storage

Support for direct OpenAI-compatible endpoints (Groq, Ollama, OpenRouter). Secrets are encrypted locally using Windows DPAPI via Electron safeStorage.
