A FEW GOOD QUESTIONS

Before you meet
your first dot.

Is this OpenAI’s official Dots app?+

Dots Desktop is an independent, open-source application inspired by OpenAI’s Dots. It brings a similar way of working to a local desktop app. It is not affiliated with OpenAI, and it does not include OpenAI’s hosted Dots service.

Will my dots work when my computer is off?+

Dots Desktop runs on your computer. Background work continues when the window is closed to the system tray, but your computer must be powered on and the app must be running. Cloud computers and cross-device messaging require additional infrastructure and are not included.

What do I need to start?+

Windows 10 or 11, and either an authenticated Codex CLI installation or an OpenAI-compatible provider. The app is free to download. Your provider’s usage charges and account limits still apply.

Where are my work and memory stored?+

Your dots, settings, run history, and memory are stored locally. Each dot works in a folder you choose. Model requests send the context needed for the task to your selected provider. API credentials are encrypted using your operating system’s credential storage.

How are permissions enforced?+

Compatible-provider tools enforce custom rules and interactive approvals. Headless Codex execution rejects dots configured with approval mode Ask or custom Ask/Deny rules. Built-in file tools check workspace boundaries; native shell commands use local computer privileges and are not confined by an operating-system sandbox. Review shell access before enabling it.

Can I connect Slack, Teams, or voice calls?+

This release focuses on the desktop experience. Official ChatGPT messaging channels, mobile sync, full voice calls, and cloud browser takeover are not bundled. See the capability comparison for what is available and what needs additional services.

How do I update from an older version?+

Download and run the 2.0 installer. Existing local settings, dots, and workspaces are retained. A portable build is also available, and the release includes checksums for both downloads.
