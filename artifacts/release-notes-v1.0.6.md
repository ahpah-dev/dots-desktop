# Dots v1.0.6 — Desktop interface polish

This update refines the existing Dots interface and adds a custom Windows title bar that follows your selected theme.

- Theme-matched title bar with minimize, maximize/restore, and close controls.
- Existing close-to-tray behavior preserved so background agents keep working.
- Refined tabs, selected agents, hover states, keyboard focus, and text contrast.
- Subtle tab and dialog animations with support for reduced-motion preferences.
- System-theme changes apply while the app is open.

Download **Dots-Setup-1.0.6.exe** to install or update Dots on Windows, or **Dots-1.0.6-portable.exe** to run it without installation. Existing agent workspaces and settings are retained by the installer update.

Validation: production build and TypeScript checks pass; all 17 existing tests pass. Window controls, close-to-tray behavior, dark/light themes, and reduced motion were checked in Electron.
